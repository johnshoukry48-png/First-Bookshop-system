# نظام محاسبة المكتبة — دليل التشغيل الفعلي (نسخة نظيفة وفارغة)

المجلد يحتوي: `index.html` (التطبيق) — `config.js` (إعداد الاتصال) — `schema.sql` (قاعدة البيانات). لا توجد بيانات تجريبية ولا وضع تجريبي.

## 1) إنشاء قاعدة البيانات (مرة واحدة، حوالي 5 دقائق)
1. أنشئ حساباً مجانياً على **supabase.com** ثم **New project** (اختر منطقة قريبة وكلمة مرور قوية للقاعدة واحفظها).
2. من القائمة: **SQL Editor ▸ New query** — افتح ملف `schema.sql` والصق محتواه كاملاً ثم **Run**. (آمن لو شغّلته مرتين.)
3. **Authentication ▸ Sign In / Providers ▸ Email**: أوقف **Allow new users to sign up** (مهم للأمان — الحسابات يُنشئها المدير فقط)، ويُفضّل إيقاف تأكيد البريد (**Confirm email**) لتسهيل إنشاء حسابات الموظفين.
4. **Authentication ▸ Users ▸ Add user**: أنشئ حسابك (بريد + كلمة مرور) ثم شغّل في SQL Editor:
   `update public.profiles set role = 'admin', full_name = 'المالك' where email = 'بريدك@example.com';`

## 2) ربط التطبيق
من **Project Settings ▸ API** انسخ **Project URL** و **anon public key** والصقهما في `config.js` (السطران `url` و`key`). لا تضع مفتاح `service_role` أبداً.

## 3) الرفع على الإنترنت (اختر واحداً — كلها مجانية)
- **Netlify Drop**: ادخل app.netlify.com/drop واسحب المجلد كاملاً — تحصل على رابط فوراً.
- **Cloudflare Pages** أو **GitHub Pages**: ارفع الملفات الثلاثة (أو المجلد) كموقع ثابت.
- أي استضافة ملفات عادية تعمل (الموقع ثابت ولا يحتاج خادماً).

افتح الرابط ← سجّل الدخول ببريدك.

## 4) أول خطوات بعد الدخول
1. **الإعدادات والهوية**: اسم المكان، اللوجو، صورة الطابع/نص الذيل، الترم الحالي، المظهر.
2. **العملاء والناشرون** أو **استيراد Excel**: أضف/استورد الأسماء (وحدّد الحد الائتماني للعملاء).
3. **الخزنة**: اكتب «الخزينة القديمة» لأول شهر (افتح القفل 🔓 بجانبها) ثم تُرحَّل تلقائياً للأشهر التالية.
4. **المستخدمون**: أنشئ الموظفين من Supabase (Authentication ▸ Add user) وسيظهرون هنا بدور «موظف»؛ غيّر الدور إلى «قراءة فقط» لمن تريده يرى بلا تعديل.
5. **استيراد Excel**: ارفع المبيعات/الدفعات/المرتجعات/المصروفات القديمة (القوالب متاحة داخل صفحة الاستيراد).

## 5) التشغيل اليومي
- فاتورة **أجل**: يُحسب الأجل تلقائياً ولا تُسجَّل طريقة دفع إلا مع دفعة. فاتورة **نقدى**: الأجل صفر ويظهر «المستحق للدفع» وتختار طريقة الدفع، ويمكن وضعها **معلقة** إن لم تُسدَّد بعد.
- رقم الفاتورة تلقائي. الدفعة بدون فاتورة يُكتب التاريخ في خانة الرقم.
- **المعلق** (من الخزنة): تعديل، أو «سداد» كلي/جزئي — الجزئي يُبقي المتبقي معلقاً.
- **تسويات الحساب**: عمولة/مبلغ على المدفوع أو المسحوب للعميل/الناشر دون المرور على الخزنة.
- **نسخة احتياطية**: الإعدادات ▸ تنزيل نسخة احتياطية (JSON) — يُنصح أسبوعياً. (Supabase المجاني يوقف المشروع بعد أسبوع بلا استخدام؛ الدخول مرة واحدة يعيده.)

## 6) الأمان
المفتاح في `config.js` هو `anon` ويظهر لأي زائر وهذا طبيعي: الحماية الفعلية في قاعدة البيانات (RLS) — الموظف يرى حركاته فقط، الخزنة للمدير، و«قراءة فقط» لا يكتب أي شيء. لا تشارك كلمة مرور قاعدة البيانات ولا مفتاح `service_role`.
